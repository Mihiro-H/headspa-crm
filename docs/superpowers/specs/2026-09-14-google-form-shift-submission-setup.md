# Googleフォームによるシフト希望提出フロー セットアップ手順書

- 日付: 2026-09-14
- 対象読者: 実際にGoogleフォームを作成し、Apps Scriptを設定する管理者
- 前提: 本手順書に対応する実装（`/api/shift-form-webhook`、パース処理、スタッフ一覧コピー機能など）はすでにコードとしてデプロイ済みであること。設計は`docs/superpowers/specs/2026-09-14-google-form-shift-submission-design.md`を参照。

この手順書に従ってGoogleフォームとApps Scriptを設定すると、スタッフがGoogleフォームからシフト希望を提出できるようになります。

---

## 1. Googleフォームの作成手順

1. [Google フォーム](https://forms.google.com)で新規フォームを作成する。
2. 以下の4つの質問を、**この順番・この文言のまま**作成する（Apps Script側で質問タイトルを完全一致で参照するため、文言を変えないこと）。

### 質問1: 対象年月

- 質問文: `対象年月`
- 形式: プルダウン
- 選択肢の例: `2026-10`
  - 対象となる月を`YYYY-MM`形式の選択肢として用意する（数ヶ月分をあらかじめ並べておき、月が変わるごとに選択肢を追加・削除する運用を推奨）。
  - 「いつ出しても来月分」のような曖昧な自動判定はしないため、毎回スタッフに明示的に選んでもらう。

### 質問2: お名前

- 質問文: `お名前`
- 形式: プルダウン
- 選択肢: `/admin/staff-shifts`画面の「フォーム用スタッフ一覧をコピー」ボタンでコピーした内容を、そのままこのプルダウンの選択肢欄に貼り付ける。
  - 選択肢は`店舗名 - 氏名`形式（例: `渋谷店 - 松本陸`、`新宿店 - 松本陸`）。同姓同名（兼任スタッフ等）を区別するため店舗名が必ず併記されている。
  - 店舗異動・入退職があった場合は、このボタンで一覧を再コピーしてプルダウンを更新すること。

### 質問3: 休み希望の日

- 質問文: `休み希望の日`
- 形式: **チェックボックス**（複数選択可）
- 選択肢: 対象月の日付を1日ずつ個別の選択肢として用意する（例: `10/1`, `10/2`, `10/3`, ... `10/31`）。
  - **重要**: Googleフォーム標準の日付ピッカー（日付形式の質問）は使わないこと。自由入力の日付ピッカーではなく、日付そのものを選択肢としたチェックボックス形式にする必要がある（Apps Script側が複数選択の回答として日付文字列の配列／カンマ区切り文字列を受け取る前提のため）。
  - 月が変わるごとに、この質問の選択肢も対象月の日付に差し替える。

### 質問4: 時短希望の日と時間

- 質問文: `時短希望の日と時間`
- 形式: 自由記述（段落）
- 説明文（フォーム上のヘルプテキストとして表示することを推奨）:
  ```
  1行につき1件、「日付 開始-終了」の形式で入力してください。
  区切りは「-」「〜」「~」のいずれでも構いません。
  開店・閉店時刻に合わせたい場合は「開店」「閉店」と書いてください。

  例:
  10/5 11:00-15:00
  10/12 開店〜14:00
  ```
- 未回答の日はすべて「出勤（店舗営業時間フル）」として扱われる。

## 2. Apps Scriptの設定

フォームの編集画面右上の「⋮」（その他のオプション）から「拡張機能 > Apps Script」を開き、デフォルトで生成されている`myFunction`などのコードを全て削除して、以下のコードをそのまま貼り付ける。

**書き換えが必要なのは`WEBHOOK_URL`と`WEBHOOK_SECRET`の2箇所だけ**。それ以外は変更不要。

```js
// ===== 書き換えが必要な設定 =====
const WEBHOOK_URL = "https://<あなたのドメイン>/api/shift-form-webhook";
const WEBHOOK_SECRET = "<.envのSHIFT_FORM_WEBHOOK_SECRETと同じ値>";
// ================================

// フォームの質問タイトルと完全一致させること
const QUESTION_TITLES = {
  yearMonth: "対象年月",
  staffLabel: "お名前",
  dayOff: "休み希望の日",
  reduced: "時短希望の日と時間",
};

function onFormSubmit(e) {
  const responses = e.response.getItemResponses();
  const answers = {};
  responses.forEach((r) => {
    answers[r.getItem().getTitle()] = r.getResponse();
  });

  const dayOffRaw = answers[QUESTION_TITLES.dayOff];
  // 日付の複数選択項目は配列で返ってくる場合と文字列（カンマ区切り）で
  // 返ってくる場合があるため両対応する
  const dayOffDates = Array.isArray(dayOffRaw)
    ? dayOffRaw
    : (dayOffRaw || "").split(",").map((s) => s.trim()).filter((s) => s !== "");

  const payload = {
    yearMonth: answers[QUESTION_TITLES.yearMonth],
    staffLabel: answers[QUESTION_TITLES.staffLabel],
    dayOffDates: dayOffDates,
    reducedFreeText: answers[QUESTION_TITLES.reduced] || "",
  };

  UrlFetchApp.fetch(WEBHOOK_URL, {
    method: "post",
    contentType: "application/json",
    headers: { Authorization: "Bearer " + WEBHOOK_SECRET },
    payload: JSON.stringify(payload),
    muteHttpExceptions: true,
  });
}
```

貼り付け後、`WEBHOOK_URL`を実際にアプリをホストしているドメイン（本番URL）に書き換え、`WEBHOOK_SECRET`を後述の`.env`に設定する値と同じ文字列に書き換える。

編集後、Apps Scriptエディタ上部のフロッピーディスクアイコン（保存）をクリックして保存する。

## 3. トリガーの設定手順

Apps Scriptがフォーム送信時に自動実行されるよう、トリガーを設定する。

1. Apps Scriptエディタ左側メニューの時計アイコン（「トリガー」）をクリックする。
2. 右下の「トリガーを追加」ボタンをクリックする。
3. 以下の内容で設定する。
   - 実行する関数を選択: `onFormSubmit`
   - 実行するデプロイを選択: `Head`
   - イベントのソースを選択: `フォームから`
   - イベントの種類を選択: `フォーム送信時`
4. 「保存」をクリックする。
5. 初回保存時にGoogleアカウントの承認を求められるので、フォームの所有者アカウントで承認する（「このアプリは Google で確認されていません」という警告が出た場合は「詳細」→「（プロジェクト名）に移動（安全ではないページ）」を選んで進める。これは自分が作成したスクリプトであるため問題ない）。

## 4. `.env`への設定

アプリの`.env`ファイルに、以下の環境変数を追加する。

```
SHIFT_FORM_WEBHOOK_SECRET=<ランダムな文字列>
```

- `<ランダムな文字列>`には、第三者に推測されない十分に長いランダムな文字列を設定する（例: パスワード生成ツールなどで生成した32文字以上の文字列）。
- **この値は、手順2でApps Scriptに貼り付けた`WEBHOOK_SECRET`と完全に同じ値にすること。** 値が異なると、Webhook呼び出しが認証エラーで拒否される。
- `.env`を変更した後は、アプリ（`npm run dev`またはデプロイ先）を再起動して環境変数を反映させる。

---

## 5. 日付選択項目に関する重要な注意

質問3「休み希望の日」は、Googleフォームの**標準の日付形式の質問（自由入力の日付ピッカー）を使ってはいけない**。

理由: このフローでは、フォームの回答をApps Scriptが複数選択項目（チェックボックス）として扱う前提で設計されている。日付ごとに個別の選択肢（`10/1`, `10/2`, ...）を用意したチェックボックス形式にすることで、スタッフは対象月の候補日の中から休みたい日を複数選んでチェックするだけで済む。

月が変わるたびに、この質問の選択肢（日付一覧）を対象月に合わせて手動で更新する必要がある。

## 6. 動作確認手順

1. Googleフォームを開き、テストとして自分自身の名前・適当な休み希望日・時短希望を入力して送信する。
2. アプリを`npm run dev`で起動している場合は、そのターミナルの出力を確認し、Webhook呼び出し（`/api/shift-form-webhook`へのPOST）でエラーが出ていないか確認する。
   - `unmatched_staff`エラーが出た場合は、質問2のプルダウンの選択肢とアプリ側のスタッフ名（`店舗名 - 氏名`）が完全一致しているか確認する。
   - 認証エラーが出た場合は、`.env`の`SHIFT_FORM_WEBHOOK_SECRET`とApps Scriptの`WEBHOOK_SECRET`が一致しているか確認する。
3. アプリの`/admin/staff-shifts`画面を開き、テスト送信した対象月・対象スタッフの「提出済みの希望」欄に、フォームで入力した休み希望日・時短希望が反映されているか確認する。
4. 時短希望の自由記述欄にわざと不正な書式の行を含めて再テストし、その行が「不明な行」としてWebhookのレスポンス（Apps Scriptの実行ログ、Apps Scriptエディタの「実行数」メニューから確認可能）に記録され、かつ他の正常な行は反映されることを確認する（任意だが推奨）。

以上で設定は完了。
